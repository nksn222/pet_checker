# AION2 ペットチェッカー v5（PCでスクショを貼り付け）

ゲームのペットショップ画面を **PCからコピーして Ctrl + V で貼り付ける** 個人用のWebアプリです。購入チェックと208種類の所持ペット管理が使えます。

## PCでの使い方

1. GitHub PagesのURLをPCの **Chrome / Edge** で開きます。
2. AION2のゲーム内でショップの**画面全体**を表示します。
3. Windowsなら `Win + Shift + S` でゲーム画面全体（ショップを含む範囲）を選択・コピーします。あるいはスクリーンショットを画像としてコピーします。
4. ページをクリックして `Ctrl + V`。OCRが開始され、確認できたペットが優先度順に並びます。画面上の「クリップボードから読み取る」も使用できます（対応ブラウザの許可が必要）。
5. 読み間違えた名前は**候補ボタン**か手動入力で修正できます。

**他の入力方法:** PNG・JPGをページにドラッグ＆ドロップ、または「画像ファイルを選ぶ」。画像をファイル保存せずに貼り付けるのが基本です。`Ctrl + V` が反応しなければページを一度クリックして試してください。クリップボードに画像が入っていない場合はスクショを撮り直してください。

## GitHub Pagesで公開する

1. このZIPを展開し、**中身**をリポジトリのルートへアップロード／上書き。`.github/workflows/update-and-deploy.yml` も含めます（隠しフォルダに注意）。
2. GitHubの **Settings → Pages → Build and deployment → Source: GitHub Actions** を選びます。
3. **Actions → ペット入手経路の更新と公開 → Run workflow** で公開します。`main` への変更でも自動実行されます。
4. 公開されたURLをPCで開きます。古い画面が残った場合は `Ctrl + Shift + R` で再読み込みします。

### 所持ペットのデータ

「所持ペット」タブで **未登録／未所持／所持Lv.1～3** を管理。ローカルストレージのキーはv2以降と同じ `aion2.pet-checker.collection.v2` にしているため、**同じURL・同じブラウザ**なら原則引き継げます。ただし、iPhoneとPCで所持情報は自動同期されません。端末を移すときは「所持ペット → バックアップ・設定 → 書き出す／復元する」でJSONを移してください。更新前のバックアップをおすすめします。

### ペット情報／判定について

- ペット名と種族：**208種類**に対応。
- 同梱データで入手経路を個別確認済み：**27/208種類**。残りは「要確認」で、推測でダンジョン限定などと決めつけません。
- 付属のGitHub ActionsはWikilyのペットページを巡回し入手元を更新できます。ただし、サイトのアクセス制限・構造変更等により208件すべての取得完了を保証するものではありません。
- 既知の入手元情報では本体の入手先と魂の入手元を区別し、ドロップ率や「限定」の確証として誤用しません。
- OCRは**提供された1440×900ショップスクショの10箇所の名前行**を基準にした位置認識です。別解像度・UI配置・アップデート後には読み取りが失敗することがあります。名前の手動修正を利用してください。
- 初回の日本語OCR（Tesseract.js）の取得にはインターネット接続が必要。OCRはブラウザ上で処理され、画像を外部サーバーへアップロードする処理は実装していません（OCRライブラリはCDNから読み込みます）。
