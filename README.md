# AION2 ペットチェッカー v6 - OCR改善版

## 今回の修正

以前のv5では、10枠のうちOCRに成功した名前だけを表示したため、見落としが生じました。v6ではスクショの定位置にある10枠を**必ず10件表示**します。ゲーム画面内で名前が「…」と省略されるケースにも配慮し、名前の部分のスクショを各結果に添付して、208種の名前データから候補を選べるようにしました。

- PCでショップを表示し、Windows の `Win + Shift + S` 等でスクショをコピー → ページで `Ctrl + V`。
- 日本語OCRはペット名の部分だけを切り出し、白文字抽出・補正（短い単語に強い認識モード）を行う。判定できない場合も画像と手動選択欄を残す。
- 10枠が1〜10の位置付きで表示され、読み違いはそれぞれの候補ボタンから修正できる。
- 正式な名前を選んだときだけ購入優先度を表示する。曖昧な「ケルビ…」等は勝手に特定しない。
- 既存の208ペット名と、所持レベル・個人メモ・JSONバックアップはそのまま。

## GitHub Pages 更新

ZIP内の全ファイルをリポジトリに**フォルダを一段増やさず**上書きアップロードしてください。Pages で公開している既存URLを開いてください。保存済みの所持ペット情報は、同じブラウザ・同じドメイン/パスで利用する限り引き継ぎます。更新後は強制再読込 Ctrl+F5 を推奨します。

## 注意点

- レイアウトはユーザー提供の1440×900ショップ全体画面を基準にしています。ほかの解像度や表示比率、UI変更では枠の位置がずれることがあります。
- 省略表示の名前はOCRでは完全復元できません。画像・候補の目視確認が必要です。
- 初回OCRの日本語モデル取得にネット接続が必要です。モデル取得に失敗しても、10枠の画像を見ながら手動選択できます。
- 入手経路の確認状況は前バージョンから引き継いでいます。**未確認のペットを限定入手と推測しません。**
- 所持情報はブラウザのlocalStorageへ保存され、同じURL・同じブラウザ内で引き継がれます。PCとiPhoneの自動同期はありません。
