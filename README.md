# AION2 ペットチェッカー v7 — 画像判定版

PCのゲームショップ画面をスクリーンショット（全画面1440×900を想定）し、Webアプリに `Ctrl + V` で貼り付ける個人用ツールです。

## v7 のポイント

- 日本語 OCR を使わず、画像の色・形・輪郭の特徴を見本画像と比較。ゲーム内で名前が `…` になっていても画像候補が出ます。
- 1440×900 のショップ10枠をそれぞれ切り出し、**10枠必ず表示**。別の画面比率は位置ずれに注意。
- 画像照合の自動確定は高い一致スコアと次点との差がある場合に限定。スコアは正答確率ではありません。
- 正しいペット名を候補ボタン／入力欄から確定すると、そのカードの画像を今後の見本としてIndexedDBに保存して学習します。
- 208種類の日本語名を検索できる図鑑と所持/未所持/理解度Lv.1～3を継続使用。所持データは旧v2～v6のlocalStorageを使用します。
- 入手経路は確認済みデータのみで購入候補を評価。詳細はWikilyの入手元ページで確認可能です。
- JSONバックアップ (schema v3) は **所持状況と学習済み画像** をセットで書き出し・復元できます。旧schema v2の所持データも復元可。

## 現時点の画像見本

同じユーザーから共有されたショップスクショ2枚をもとに、名前と見た目が照合できる**13種類**の画像見本のみを初期収録しています（`references/index.json`）。
**208種類すべての画像見本が用意済みという意味ではありません。** 未登録種は画像が似た候補を表示するだけで、無理に自動確定しません。
ペットを自分で確定していけば見本が増え、次回以降は画像で判別しやすくなります。

## 使い方

1. ZIPを展開してすべてのファイルをGitHubリポジトリのルートへアップロードします（`references/`フォルダも必要）。
2. 既存のGitHub Pagesを更新。`Settings → Pages` で公開先を確認（付属GitHub Actionsでの公開も可能）。
3. AION2でショップ画面を表示し、`Win + Shift + S` でショップ全体をクリップボードにコピー。
4. サイトで `Ctrl + V`。10枠の画像を照合して、確信できたものだけ自動確定します。
5. 違う・不明な枠は画像候補か正式名を選択して「確定」。**その画像が次回の見本**になります。
6. 所持ペットタブで所持状況を記録。大切なデータはJSONでバックアップします。

## 注意点

- 自動識別は自分のショップと同じ**ゲーム内アイコン**を学習する方式。ペットの外見が酷似する場合、背景や解像度が変わる場合は手動で再確認してください。
- v7は画像見本の自動スクレイピングを実装していません。Wikiの208種類の**名前**と、画像見本13種類のカバレッジを区別しています。
- ブラウザで自分が登録した画像はIndexedDB、所持状況はlocalStorageに保存されます。Chrome/Edgeなど別ブラウザでは自動共有されません。シークレットモードの削除やブラウザデータ消去に注意。
- 公開GitHub Pagesは第三者からアクセスできることがあります。元のショップ全画面スクショはZIPに入れていませんが、最初の13種類の小さなアイコン画像は公開ファイルに含まれます。
- 「入手経路27/208」は今回の参考DBに出典確認が記録されている件数であり、208件の入手元が確認済みではありません。Wikilyの仕様変更でGithub Actionsの取得が失敗する場合があります。
- v7では頭から終わりまでのPCブラウザ統合テストを実行できず、JavaScript構文・データ整合性・特徴量照合の確認まで行いました。ChromeかEdgeの最新版で動作を確認してください。
